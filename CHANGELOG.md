# Changelog

Notable user-facing changes to Elbowroom. Versions follow [Semantic Versioning](https://semver.org/),
with entries organized using [Keep a Changelog](https://keepachangelog.com/).

## [Unreleased]

## [1.1.0] - 2026-09-16

### Added
- A drag-to-Applications installer for Apple Silicon and Intel Macs.
- Automatic update checks and a Check for updates menu command.
- Clearer storage groups for app caches, developer tools, and personal libraries.

### Changed
- Every feature is free, with no reclaim limit or paid upgrade.
- Cleanup plans explain what will be removed and request administrator approval when needed.
- Elbowroom is available as a direct download only. External-drive offloading is retired.

### Fixed
- Installed copies find their sounds and help images without the development checkout.
- Scanning, search, and startup keep more work off the interface thread.

## [1.0.0] - 2026-09-16

### Added
- Initial GitHub release of Elbowroom.
