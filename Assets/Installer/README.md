# Installer artwork

The neutral background and drag arrow are copied from Dorso's installer.
`Scripts/make-dmg.sh` uses the same 654 × 444 Finder window and icon positions,
with Elbowroom's app icon and volume name. The 2× source is retained alongside
its standard-resolution counterpart.

Dorso artwork is covered by the [original MIT notice](../../docs/licenses/Dorso-MIT.txt).
